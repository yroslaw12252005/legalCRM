Настройка в Tilda

  1. Откройте «Настройки сайта → Формы → Webhook».
  2. Вставьте Webhook URL нужного подключения.
  3. Выберите API Method: Header.
  4. Укажите API Name: X-Tilda-Token.
  5. Вставьте API Key, показанный CRM при создании подключения.
  6. Сохраните настройку, включите Webhook в блоке формы и опубликуйте страницу.
